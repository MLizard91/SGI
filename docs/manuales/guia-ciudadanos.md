# Guía de usuario para ciudadanos

## Para qué sirve

La aplicación móvil SGI Mexticacán permite enviar incidencias relacionadas con Alumbrado Público, Parques y Jardines, Aseo Público, Obras Públicas y Agua Potable, y consultar su atención.

## Antes de empezar

- Instala **Expo Go** si el Ayuntamiento te comparte una versión de pruebas mediante un código QR. En una versión publicada, instala la aplicación desde el medio oficial que indique el Ayuntamiento.
- Para usar la versión de pruebas, conecta el teléfono a la red indicada por soporte y abre el enlace o escanea el QR de Expo.
- Permite el acceso a la cámara, las fotografías y la ubicación cuando el teléfono lo solicite. La ubicación y la dirección ayudan a identificar el lugar del problema.
- Mantén acceso a tu correo electrónico y no compartas tu contraseña.

## Crear una cuenta

1. Abre la aplicación y pulsa **Regístrate**.
2. Escribe tu nombre, correo y contraseña. Apellidos y teléfono son opcionales.
3. La contraseña debe tener al menos 8 caracteres. Escríbela de nuevo para confirmar.
4. Pulsa **Crear cuenta**. El registro crea un perfil de ciudadano.

Si ya tienes cuenta, escribe tu correo y contraseña en la pantalla de inicio de sesión. Al terminar, usa **Salir** para cerrar la sesión en un dispositivo compartido.

## Enviar un reporte

1. En **Mis reportes**, pulsa **＋ Reportar**.
2. Selecciona el área y después la categoría que mejor describa el problema.
3. Escribe un título claro y una descripción con detalles útiles (qué sucede, desde cuándo y referencias del lugar).
4. Agrega al menos una fotografía. Se admiten de 1 a 5 imágenes por reporte; puedes tomar una foto o elegirla de la galería.
5. Revisa la ubicación GPS en el mapa. Puedes tocar el mapa o mover el marcador para corregirla. Si el GPS no está disponible, marca el punto manualmente.
6. Confirma o escribe la dirección y la comunidad/colonia si hace falta.
7. Revisa la información y pulsa **Enviar reporte**.

La aplicación confirma el envío y muestra un folio (por ejemplo, `MEX-000123`). Conserva el folio para identificar el reporte cuando solicites ayuda.

## Consultar avances y responder

1. Abre **Mis reportes** para ver los reportes de tu cuenta. Desliza hacia abajo para actualizar la lista.
2. Pulsa un reporte para ver su folio, estatus, fotos, ubicación, historial y evidencias de atención.
3. El sistema puede reflejar cambios de estatus en tiempo real mientras la aplicación está conectada.
4. En **Comentarios**, escribe información adicional o responde al personal y pulsa **Enviar comentario**.

Los estatus del flujo son **Recibida**, **En revisión**, **Asignada**, **En proceso**, **Resuelta**, **Cerrada** y **Rechazada**. Un reporte rechazado muestra una indicación para revisar los comentarios. Si un caso requiere aclaración, usa los comentarios del reporte o los canales de contacto oficiales del Ayuntamiento.

## Recomendaciones

- Envía un reporte por problema y selecciona el área que corresponda.
- No incluyas contraseñas ni información personal innecesaria en la descripción o en los comentarios.
- Evita fotografías de personas, placas u otros datos privados cuando no sean necesarios para documentar el problema.
- No envíes reportes de prueba en el servicio oficial.
- Si el envío falla, guarda la descripción y prueba nuevamente cuando tengas conexión. Verifica primero en **Mis reportes** que no se haya creado ya el reporte para evitar duplicados.
