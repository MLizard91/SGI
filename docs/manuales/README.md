# Manuales y documentación de SGI Mexticacán

Documentación dirigida a ciudadanía, personal municipal y responsables técnicos.

## Manual ilustrado en PDF

- [Guía de flujos, pantallas y botones (PDF)](../../Guia-flujos-pantallas-botones-SGI-Mexticacan.pdf): recorrido funcional de la app móvil y el panel web, controles, permisos por perfil y seguimiento. La [fuente HTML](./guia-flujos-pantallas-botones.html) es editable.
- [Manual de operación por perfil (PDF)](../../Manual-operacion-SGI-Mexticacan.pdf): procedimientos diarios en secciones separadas para ciudadanía, Administración, Recepción, Encargado y Operativo.
- [Manual de mantenimiento técnico (PDF)](../../Manual-mantenimiento-SGI-Mexticacan.pdf): operación, configuración, respaldos, actualización y recuperación.
- [Manual paso a paso para crear reportes por perfil (PDF)](../../Manual-uso-reportes-por-perfil-SGI-Mexticacan.pdf): inicio de sesión y flujo de creación en móvil para ciudadanía, Administrador, Encargado de Área y Responsable Operativo. El [HTML fuente](./manual-uso-reportes-por-perfil.html) permite actualizar el contenido; las pantallas móviles de ejemplo se generan desde [esta plantilla](./pantallas-ilustrativas-app.html).
- [Manual de usuarios por perfil (PDF)](../../Manual-usuarios-por-perfil-SGI-Mexticacan.pdf): versión lista para compartir o imprimir. Incluye capturas del panel municipal y guía por cada perfil.
